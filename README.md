# Mali Services Pro

Application mobile Flutter destinée aux artisans et professionnels inscrits sur la plateforme Mali Services.

## Fonctionnalités

- parcours d'accueil professionnel ;
- connexion à l'écosystème Mali Services ;
- interface adaptée aux besoins des prestataires ;
- préparation à la gestion du profil et des services ;
- support Android, iOS, Web, Linux, macOS et Windows.

## Stack technique

- Flutter et Dart ;
- Material 3 ;
- `http` pour les échanges avec l'API ;
- `shared_preferences` pour les données de session ;
- génération d'icônes de lancement.

## Installation

```bash
flutter pub get
flutter run
```

Pour les tests :

```bash
flutter test
```

## Architecture

Le code principal se trouve dans `lib/`, les ressources visuelles dans `assets/` et les tests dans `test/`.
